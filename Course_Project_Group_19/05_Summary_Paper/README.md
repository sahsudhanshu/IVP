# Project report

`Project_Report.pdf` is the 12-page course project report; `Project_Report.tex`, the Springer `llncs.cls`, and its figure files are provided for rebuilding. Compile twice with `pdflatex Project_Report.tex` in this folder. The references use an embedded bibliography. Cited paper PDFs are in `../07_Research_Papers/`.

`Summary_Paper.pdf` and `Summary_Paper.tex` are the earlier, shorter review. Group members should review and approve the report and complete the instructor-required originality checks before submission.
