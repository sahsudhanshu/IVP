# Research papers cited in the summary report

This folder contains the PDF for each of the 12 references in `../05_Summary_Paper/Summary_Paper.tex`. The files beginning `BasePaper_1` and `BasePaper_2` identify the two model papers. The remaining PDFs are supporting references, not additional base papers.

- `BasePaper_1_TSN_GRU.pdf` — Bui and Nguyen, TSN–GRU.
- `BasePaper_2_DVANet.pdf` — Siddiqui et al., DVANet.
- `Cho_2014_GRU.pdf` — GRU encoder–decoder.
- `Nguyen_2021_Cross_View_Attention.pdf` — cross-view attention.
- `Shah_2023_Multiview_Contrastive.pdf` — multi-view contrastive learning.
- `Simonyan_2014_Two_Stream.pdf` — two-stream action recognition.
- `Szegedy_2016_Inception_v3.pdf` — Inception architecture.
- `Vyas_2020_Cross_View_Prediction.pdf` — cross-view video prediction.
- `Wang_2018_DA_Net.pdf` — dividing and aggregating network.
- `Wang_2014_NWUCLA.pdf` — NW-UCLA cross-view action modeling.
- `Wang_2016_Temporal_Segment_Networks.pdf` — temporal segment networks.
- `Yang_2026_TBCNet.pdf` — trunk-branch contrastive network.
