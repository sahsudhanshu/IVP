# Group 19 submission guide

Submit the complete `Course_Project_Group_19` folder in the numbered structure. Copy it to the lab computer and upload the folder itself to the designated Group 19 Drive folder. Only the designated group member should request access if needed.

The project report is `05_Summary_Paper/Project_Report.pdf`, with its LaTeX source and figures alongside it. The project poster is in `08_Poster`. The demo needs the entire `04_Project_Demo` folder and the model in `12_Trained_Models` together. The demo currently uses the recorded Kaggle model; the separate reported 78% local run has no independently identified checkpoint in this folder.

Before submission: record a short MP4 or AVI screen recording showing the demo being launched, a video selected, Classify pressed, and the resulting label. Put the recording in `04_Project_Demo`. The existing sample AVI is input data, not the required screen recording. Confirm the presentation is the one actually presented, have members approve the report and supply individual contribution statements, and perform the required originality checks.
