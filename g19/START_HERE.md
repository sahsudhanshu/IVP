# Group 19 course project

Start with `README_RESULTS.md` for the verified measured results and experiment limitations. `documentation/` contains the SRS, design report, literature survey and SRS/design presentation. `presentations/` contains the other group presentations. `code/` contains the historical and measured augmentation experiments, BN-Inception baseline and dataset preparation. `results/` contains the original measured logs, predictions, metrics, figures, split manifest and checkpoints. `dataset/` contains the NW-UCLA RGB archive. `references/` and `supporting_materials/` contain project references and supporting files.

The project owner reports a local augmentation result of 78.47% accuracy and 0.7845 macro-F1; the supplied files are in `results/local_run_user_supplied/`. A separate Kaggle experiment is retained with its own outputs and checkpoints. See `README_RESULTS.md` for provenance and limitations. The SRS/design presentation predates that result. The archive has not been changed. Reproduction requires the dependencies and original dataset attribution noted in the results report.

The package was assembled from available project files; check Classroom for any additional required file names or submission format before uploading.
