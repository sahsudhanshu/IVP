# Summary research paper

`Summary_Paper.pdf` is the 15-page Springer-format summary paper based on two selected papers (Bui and Nguyen, multi-branch TSN with GRU; Siddiqui et al., DVANet). `Summary_Paper.tex`, the Springer `llncs.cls` and the figure files `learning_curves.png` and `sample_segments.png` are provided for rebuilding. The confusion matrix is drawn in the `.tex` itself (TikZ) from the saved counts; `confusion_matrix.png` is kept as the original run output and is not used by the paper. Compile twice with `pdflatex Summary_Paper.tex` in this folder (use `pdflatex`, not `latex`). The references use an embedded bibliography, and the cited paper PDFs are in `../07_Base_Papers/`.

The learning curves and confusion matrix are from the recorded Kaggle run (39.47%); `sample_segments.png` shows frames from the demo clip. The 78.47% value (reference run) and the 86.12% value (improved ResNet-18/Transformer architecture, run files in `ImprovedIVP/ivp_improved_architecture/runs/experiment_01/`) are cited in the paper as project-reported results and are not tied to the learning-curve figure; the confusion matrices in Fig. 7 are drawn in TikZ from the saved prediction counts of the recorded run and of the improved run. Only the view-3 direction is reported, because only it has saved prediction files.
